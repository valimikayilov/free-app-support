# Stagefold privacy policy

Effective September 27, 2026.

Stagefold is a free Mac agenda and presentation timer by Vali Mikayilov.

## Data stays on your Mac

Stagefold does not collect, transmit, sell, or share your data. It has no account system, analytics, advertising, tracking SDKs, purchases, or network backend. The application has no network entitlement.

Agendas, cue titles, optional speaker names, private notes, timing state, settings, and the latest 30 rehearsal reports are stored locally in the app's sandbox. A running rehearsal restores paused at its last saved checkpoint after the app restarts. The app does not use iCloud synchronization.

## Files you choose

You can import an agenda JSON file and export JSON agendas or CSV rehearsal reports using macOS file dialogs. Those files are read or written only as part of the action you choose. Exports contain the agenda or report information you selected, including any speaker names and notes included in agenda JSON. Keep exported files wherever you consider appropriate.

The separate stage display omits private notes and operator controls. It displays the current cue title, optional speaker, timer, and optionally the next cue. Information shown on an external display or in a screen share is visible to that audience.

## Optional controls

The sound option plays a local macOS sound. The keep-awake option requests that macOS remain awake while a timer is running. Both settings are off by default. Neither sends data off the device.

## Support links and retention

Support and privacy links open GitHub in your browser. GitHub operates under its own privacy policy. If you contact support or post a public issue, the information you choose to include is handled by that service. Do not include private agenda files in public issues.

You can remove agendas inside the app and export copies before doing so. The app retains the latest 30 rehearsal reports; older reports are replaced as new ones are completed. You can remove the app's local data using macOS file management. If a library is damaged, the recovery action preserves a separate backup before creating a new library.

This policy will be updated if the app's data practices change. Questions can be raised through the [support repository](https://github.com/valimikayilov/free-app-support).
