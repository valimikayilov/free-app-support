# ChromaMoor privacy policy

Effective September 27, 2026.

ChromaMoor does not collect, transmit, sell, or share personal data. It has no account, advertisements, tracking, analytics, third-party SDKs, or network entitlement.

Palette names, swatch names, colors, selected palette, and the last valid contrast pair are processed and saved locally in a JSON file inside the app's sandboxed Application Support folder. Undo history remains in memory during the session. Resetting an unreadable library first copies the original file to a local backup. Backups remain local until you manage them through Show local storage.

Images are read only when you choose a file or the included sample. The app samples their first frame locally and never modifies the source. Sampled pixels and the filename remain in memory during the session; images are not stored in the palette library. Adding an extracted palette stores only its name and colors.

Palette, CSS, SVG, and library exports contain the selected color data and names; library backups also contain the saved contrast pair. Exports are written only to locations you choose. You control whether to share them.

Copy controls write color values or CSS to the macOS clipboard only when pressed. Normal text editing supports standard copy and paste. The app does not monitor the clipboard.

Help and Privacy Policy open this public repository in your browser. GitHub and your browser have their own privacy practices. Support issues are public; avoid personal or confidential information.

Contact: [public support issues](https://github.com/valimikayilov/free-app-support/issues).
